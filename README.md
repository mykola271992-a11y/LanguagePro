# Language Pro 3.2 — Android

Версія 3.2 встановлюється як окремий застосунок із пакетом `ua.deutschpro.player.v32`, щоб не конфліктувати з попередніми APK. Збережено формат уроків, 9 вбудованих уроків, плеєр та фоновий MediaSession/foreground service.

## Новий урок
- У меню «Уроки» обрати «Створити урок українською» або «Додати урок з файлу» (UTF-8 TXT, одна фраза на рядок).
- Ввести назву, обрати одну із семи мов (DE, EN, CS, PL, FR, ES, IT), залишити прапорець автоматичного перекладу та натиснути «Зберегти». Можна імпортувати слова окремими рядками, довгі фрази без обмеження на кількість символів у рядку або двомовні рядки `іноземна фраза | українська фраза`. Для слів без перекладу зніми прапорець автоматичного перекладу; додаток озвучить слово двічі німецьким голосом. Для імпорту українського тексту залиш прапорець і вибери мову перекладу. Файл обмежений 10 МБ для стабільної роботи пристрою.
- ML Kit Translation 17.0.3 завантажує мовні моделі при першому використанні (інтернет і вільне місце потрібні; можливе мобільне завантаження). Надалі переклад на пристрої працює без мережі після завантаження моделей. Машинний переклад може містити помилки.
- Бібліотеку можна фільтрувати за мовою; наступні уроки відтворюються в межах поточної мови. Для відтворення використовуються відповідні мовні голоси Android. Офлайн-озвучка залежить від установленого TTS і голосів. Старий ключ JSON `de` залишається внутрішнім полем іншомовного тексту для сумісності.

Приклади файлів для імпорту є в теці `examples/`.

## Оформлення
- У меню «Опції» можна вибрати одну з трьох тем: темна м’ятна, світла або синя. Вибір зберігається та застосовується до плеєра й голосового перекладача.

## Голосовий перекладач
- У нижньому меню «Переклад» або з плеєра відкривається окремий екран. Урок ставиться на паузу.
- Вибрати мову, натиснути напрямок перекладу для перемикання (українська ↔ вибрана мова), натиснути «Говорити» та продиктувати фразу в системному сервісі Android. Розпізнаний текст автоматично перекладається. Також можна вводити й редагувати текст вручну.
- Є автоматична озвучка, повторне прослуховування і збереження двомовної фрази в бібліотеці як окремого уроку.
- Голосове розпізнавання використовує встановлений системний сервіс Android через RecognizerIntent. Доступність українського й інших голосів, використання мережі та обробка аудіо залежать від цього сервісу. Мікрофон належить системному сервісу; якщо він відсутній, доступний ручний ввід. Сам переклад через ML Kit після завантаження моделей може працювати офлайн.
- Це послідовний переклад фраз, не синхронний переклад неперервної розмови.

## Збірка
JDK 17, Android SDK 35, Gradle 8.9: `gradle :app:assembleDebug`. Або розпакувати в окремий GitHub-репозиторій; workflow `.github/workflows/build.yml` збирає debug APK (Actions → Artifacts). Не замінювати чинний репозиторій іншого застосунку.

Стан: версія 3.2 вихідного коду. Для APK потрібні JDK 17, Android SDK 35 і Gradle 8.9. Цей APK встановлюється окремо й не замінює попередню версію.
