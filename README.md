# Language Pro 3.1

Android-аудіоплеєр для вивчення мов: 9 уроків німецької (165 фраз), додавання власних уроків, автоматичний переклад з української на 7 мов, голосовий перекладач, озвучка та фонове відтворення.

## APK
[GitHub Actions](https://github.com/mykola271992-a11y/LanguagePro/actions) → успішна збірка → Artifacts → Language-Pro-3.1-APK → розпакувати ZIP → встановити Language-Pro-3.1.apk.

Збірка є тестовою (debug). Для оновлення вже встановленої програми потрібен той самий ключ підпису. Не видаляйте попередню версію без резервної копії уроків.

## Переклад
Перший запуск мовної моделі потребує інтернету; надалі ML Kit може перекладати офлайн. Розпізнавання голосу та озвучка залежать від установлених сервісів Android.

Локальна збірка: JDK 17, Gradle 8.9, Android SDK 35; `gradle :app:assembleDebug`.
